## Overview
A web portfolio built with Next.js 16 and React 19 to present engineering work across Python computer vision, Pygame grid simulation, Java concurrency and desktop systems, Unreal Engine 5 mechanics, and AI-assisted full-stack web delivery.

### Featured Projects
1. **Photography Portfolio & Visual Archive** (`amin-photography.vercel.app`):
   - Server-side EXIF telemetry extraction via `ExifReader`.
   - Before and After slider comparing flat RAW captures with finished color grades.
   - Python pre-build verification pipeline validating RAW/JPEG asset pairs and metadata normalization.
2. **Galactic Crafters: Factory Simulation & Grid Logistics** (`amin9127.itch.io`):
   - Over 2,000 lines of modular Python and Pygame implementing a 40x40 directional conveyor and crafting grid.
   - Cluster drag collision optimization and binary pickle state persistence.
3. **Facial Age Group Classifier (`AgeGroupCNN`)**:
   - Custom PyTorch CNN classifying four age cohorts (`Child`, `Young`, `Middle-Aged`, `Senior`).
   - Inverse-frequency weighted `CrossEntropyLoss` solving dataset skew, benchmarked against HOG + SVM/MLP baselines.
4. **Handwritten Digit Recognition & Calibration Engine**:
   - OpenCV (`cv2`) grid extraction and Scikit-learn multinomial classification with confidence calibration diagnostics.
5. **First-Person 3D Systems (Unreal Engine 5.7)**, **Hack-A-Health (Python)**, **Lancaster's Music Hall (Java 17 / SQLite)**, **Concurrency Systems (Java / LTSA)**, and **IN2011 TCP Sockets (Java)**.
